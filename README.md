# 3BIM_PROVA P1
🧩 MISSÃO: OPERAÇÃO COLABORADORES

Uma equipe de desenvolvimento está trabalhando na evolução de um projeto coletivo. O projeto possui um arquivo chamado COLABORADORES.TXT, que funciona como o registro oficial das pessoas que participaram das melhorias.

Você foi convidado a fazer parte dessa equipe. Porém, existe uma regra importante: o projeto principal não deve ser alterado diretamente. Sua contribuição deverá passar pelo fluxo de colaboração do GitHub e ser analisada antes de chegar à versão oficial.

🎯 Sua missão

Para concluir a atividade, você deverá:

01- Fazer um Fork do repositório do projeto ( PROFESSOR)  para a seu repositório remoto ( SEU GITHUB).

02- Criar uma pasta no seu computador para trabalhar no projeto.

03- Preparar essa pasta para o versionamento.

04- Conectar o repositório local ao seu Fork ( repositório remoto) .

DICA: git remote add origin https://github.com/SEU-USUARIO/3BIM_PROVA.git

Substitua SEU-USUARIO pelo seu usuário do GitHub.

05- Trazer para o computador os arquivos existentes no seu Fork ( Agora, do SEU gitHub para o o seu GIT ).

06- Criar um novo arquivo chamado keygen.txt e inserir nele:

123456           
Impeça o arquivo keygen.txt de ser versionado.

***ATENÇÃO **** . 

Para que o passo 6.0 funcione, o arquivo keygen.txt AINDA não pode estar versionado. Logo, crie o arquivo, alimente o mesmo, faça o processo para impedir que ele "suba" e só depois versione.

07- Alimentar o arquivo COLABORADORES.TXT com:

seu nome completo:

seu e-mail institucional:

nota desejada ( 0 - 10 ):

08- Preparar e registrar suas alterações no repositório local.

09- Enviar suas alterações para o seu Fork ( subir de volta para o GitHub).

10-Criar um Pull Request direcionado ao repositório original do professor.

Na descrição do Pull Request, explique brevemente quais alterações você realizou e onde encontrou maior dificuldade.
_______________________
⚠️ Atenção

O arquivo:  keygen.txt

não deverá aparecer entre os arquivos enviados ao GitHub.

O arquivo:  COLABORADORES.TXT

deverá conter obrigatoriamente seu nome, seu e-mail institucional e Nota que deseja.

🏁 Linha de chegada

A atividade estará concluída quando seu Pull Request estiver criado e aguardando análise.


💡 Dica para o git remote: o endereço utilizado deve ser o endereço do seu Fork, e não o endereço do repositório original do professor.
