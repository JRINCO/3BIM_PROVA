# 3BIM_PROVA P1
🧩 MISSÃO: OPERAÇÃO COLABORADORES

Uma equipe de desenvolvimento está trabalhando na evolução de um projeto coletivo. O projeto possui um arquivo chamado COLABORADORES.TXT, que funciona como o registro oficial das pessoas que participaram das melhorias.

Você foi convidado a fazer parte dessa equipe. Porém, existe uma regra importante: o projeto principal não deve ser alterado diretamente. Sua contribuição deverá passar pelo fluxo de colaboração do GitHub e ser analisada antes de chegar à versão oficial.

🎯 Sua missão

Para concluir a atividade, você deverá:

Fazer um Fork do repositório do projeto ( PROFESSOR)  para a seu repositório remoto ( SEU GITHUB).
Criar uma pasta no seu computador para trabalhar no projeto.
Preparar essa pasta para o versionamento.
Conectar o repositório local ao seu Fork ( repositório remoto) .
DICA: git remote add origin https://github.com/SEU-USUARIO/Atividade-S17-fork-pull-request.git

Trazer para o computador os arquivos existentes no seu Fork.

Criar um novo arquivo chamado keygen.txt e inserir nele:

123456

Criar um .gitignore que impeça o arquivo keygen.txt de ser versionado.
Alimentar o arquivo COLABORADORES.TXT com:
seu nome completo;
seu e-mail institucional.
Revisar o arquivo PROJETO.TXT e corrigir os problemas encontrados.
Preparar e registrar suas alterações no repositório local.
Enviar suas alterações para o seu Fork.
Criar um Pull Request direcionado ao repositório original do professor.
Na descrição do Pull Request, explique brevemente quais alterações você realizou.
⚠️ Atenção

O arquivo:

keygen.txt

não deverá aparecer entre os arquivos enviados ao GitHub.

O arquivo:

COLABORADORES.TXT

deverá conter obrigatoriamente seu nome e seu e-mail institucional.

🏁 Linha de chegada

A atividade estará concluída quando seu Pull Request estiver criado e aguardando análise.

Não é necessário realizar o Merge.

💡 Dica para o git remote: o endereço utilizado deve ser o endereço do seu Fork, e não o endereço do repositório original do professor.
